We are pleased to inform you that we now support Ubuntu 26.04 (Resolute Racoon) 
for new ring node installs.

We will be supporting Ubuntu 22.04 for some time to come, but no later than
the security maintenance end date set by Canonical (May 2027). Further updates 
on our plans to upgrade existing ring nodes will follow once a timeline has been
determined.

If you have any questions or concerns, please let us know.
